# 루미 런 2.0

## 게임을 켜고 참가하기

1. **`루미런-시작.cmd`를 두 번 클릭**하고 실행 창을 열어 둡니다. 이미 서버가 켜져 있으면 바로 다음 단계로 갑니다.
2. 브라우저에서 **http://localhost:3000/** 을 엽니다.
3. 혼자 하려면 맵을 고르고 **혼자 연습하기**를 누릅니다. 연습은 무한 재도전입니다.
4. 함께 하려면 **교사 · 방 만들기**에서 경기 방식과 **몇 명**을 정하고 방을 만듭니다. 방에서 맵·코스 길이·목숨을 선택한 뒤 **설정 적용**을 누릅니다.
5. 다른 브라우저에서 같은 주소를 열고 **닉네임과 참가 코드**를 입력합니다. 교사는 관전 전용이므로 두 학생이 겨루려면 교사 화면 1개와 학생 화면 2개를 엽니다.
6. **참가자 누구든 ‘다 함께 시작’을 누르면 현재 참가자가 3초 뒤 함께 출발합니다.** 준비 체크는 필요 없습니다. 경기 중 들어온 사람은 다음 경기까지 관전합니다.

PC는 방향키/A·D 이동, Space/위쪽/W 점프입니다. 휴대폰은 **가로 모드**에서 왼쪽 이동 버튼과 오른쪽 점프 버튼을 두 손가락으로 누르세요. 세로 화면에도 안내를 표시하고 조작은 유지합니다.

## 5개 맵과 난이도

| 맵 | 난이도 | 주요 도전 |
|---|---|---|
| 초원 | 입문 | 넓은 징검다리, 계단, 위험문 |
| 공중정원 | 쉬움 | 공중의 2단 이동 발판, 연속 점프 |
| 사막 | 보통 | 반대 방향으로 오르내리는 두 승강석, 갈라진 다리 |
| 수정동굴 | 도전 | 가로 바닥 장벽, 머리 위 장벽, 연속 높낮이 |
| 별빛공장 | 익스트림 | 급가속 운반로 직후 절벽, 복합 공중 관문 |

**30·45·60·90초는 코스 길이 선택이며 제한 시간이 아닙니다.** 기록은 경과 시간으로 표시합니다. 실제 완주 시간은 맵과 조작에 따라 달라집니다.

## 경기 규칙

- **먼저 도착한 사람 보상:** 지정한 인원만큼 완주하면 종료하고 상위 완주자를 선정합니다. 마지막 자리에 같은 틱으로 들어오면 공동 선정합니다.
- **꼴찌 선정:** 지정 인원만큼 목숨을 모두 잃으면 즉시 종료하고 먼저 탈락한 순서로 선정합니다. 그보다 먼저 첫 완주자가 나오면 그 시점에 종료합니다. 탈락자를 먼저 포함하고, 나머지는 현재 가장 뒤에 있는 순서로 채웁니다. 같은 탈락 틱·위치의 경계 동점은 공동 선정합니다.
- **목숨:** 두 방식 모두 무한·1·3·5번. 낙하와 위험 접촉으로 차감합니다. 무한은 계속 체크포인트에서 부활합니다.
- **강제 종료:** 교사 화면에서 언제든 종료합니다. 완주자가 없는데 강제 종료하면 도착 보상은 선정하지 않습니다.
- 도착 모드에서 전원 탈락해 완주자가 없으면 자동으로 선정하지 않고 교사의 강제 종료를 기다립니다. 종료 후 같은 방에서 재경기할 수 있습니다. 완주자가 있지만 선정 인원보다 적고 더 달릴 사람이 없으면 실제 완주자만 선정합니다.
- 연결이 끊긴 사람, 관전자, 개발용 봇은 사람용 선정에서 제외합니다. 상세는 [경기 규칙](docs/RULES.md)입니다.

교사 화면은 현재 가장 앞에 있는 참가자를 따라갑니다. 각 학생 화면은 자신의 캐릭터를 유지합니다. 닉네임은 캐릭터 위에 표시하며, 화면 아래 전체 참가자 진행 표시로 멀리 떨어진 친구도 확인할 수 있습니다.

## 휴대폰으로 참가하기

PC와 휴대폰을 **같은 Wi-Fi**에 연결하고, 교사 방의 **같은 Wi-Fi 주소 또는 QR**을 사용하세요. 휴대폰에서 `localhost`를 입력하면 PC에 연결되지 않습니다. 주소는 네트워크마다 달라집니다.

서버 실행 창, 같은 Wi-Fi 연결을 먼저 확인하세요. 학교망은 기기 사이 접속을 막을 수 있습니다. 방화벽 전체를 끌 필요는 없습니다. 외부 인터넷 공개 배포는 별도 단계입니다.

## 개발·배포 방식 실행

Node.js 22.12 이상이 필요합니다. 프로젝트 폴더의 PowerShell에서:

```powershell
npm.cmd ci
npm.cmd run dev
```

배포용 파일로 실행:

```powershell
npm.cmd run build
npm.cmd start
```

코드를 바꾼 뒤 실행기를 사용하려면 먼저 다시 빌드하세요. 같은 포트의 서버를 두 개 켜지 마세요. 서버를 다시 켜면 방은 사라지므로 새 참가방을 만듭니다. 결과는 JSON 저장 또는 강의 앱 연결로 보관합니다.
