# 경기 규칙 2.0

서버가 60틱/초로 이동·충돌·목숨·도착을 확정하고 상태를 20회/초 전송합니다. 학생은 위치나 완주 결과를 직접 결정할 수 없습니다.

## 출발과 시간

방에 참가한 누구든 시작할 수 있습니다. 현재 연결된 참가자 전체가 3초 카운트다운 후 출발하며 준비 체크는 없습니다. 교사는 관전 전용입니다. 최대 학생 30명이며 선정 인원은 참가 인원 이하여야 합니다. 시작한 뒤 신규 참가자는 관전자입니다. 설정 변경과 강제 종료·재경기는 교사만 가능합니다.

30·45·60·90초 옵션은 코스 길이입니다. 시간 만료 종료는 없습니다. 완료하지 못한 참가자가 있어도 갑자기 최대 거리로 도착 보상자를 대신 뽑지 않습니다.

## 도착 보상

지정 N명 이상이 완주한 서버 틱에 종료합니다. 완주 틱 오름차순으로 상위 N명을 고르며 경계의 동점자는 모두 포함합니다. N명보다 많이 선정될 수 있습니다. 완주자는 더 달리지 않고 자신의 화면에서 기록을 확인합니다.

모든 유효 참가자가 완주·탈락하여 더 달릴 사람이 없고 완주자가 있다면 실제 완주자만 선정합니다. 전원이 탈락해 완주자가 없다면 교사가 강제 종료하고 재경기할 수 있도록 대기합니다. 강제 종료 때 완주자가 없으면 보상자를 꾸며내지 않습니다.

## 꼴찌 선정

다음 두 조건 중 먼저 발생한 서버 틱에 종료합니다.

1. 목숨을 모두 잃은 연결 참가자가 N명 이상: 먼저 탈락한 순서로 N명을 선정하며 경계의 같은 틱 탈락자는 공동 선정합니다.
2. 첫 완주자 발생: 이미 탈락한 사람을 탈락 순서로 먼저 포함하고 남은 자리를 **그 시점의 현재 x 위치가 가장 뒤인 참가자**부터 채웁니다. 과거 최대 진행 거리를 사용하지 않습니다. 위치는 정수 픽셀로 비교하며 경계 동점은 공동 선정합니다. 완주자는 미완주자보다 뒤 순서입니다.

교사가 일찍 강제 종료한 경우에도 그 시점의 탈락·현재 위치 기준으로 처리하고 강제 종료 사실을 결과에 남깁니다.

## 목숨과 연결

목숨은 무한(코드 값 0)·1·3·5번으로 두 모드에 공통 적용합니다. 위험 막대 접촉과 낙하가 1회를 소모합니다. 남은 목숨이 있거나 무한이면 0.8초 뒤 직전 안전 깃발에서 재출발합니다. 연습은 선택한 목숨과 관계없이 무한 재도전입니다. 마지막 생존 모드와 추격 경계는 제거했습니다.

끊긴 참가자의 입력은 해제되지만 물리는 진행합니다. 같은 ID와 비밀 토큰으로만 재접속하며 목숨·탈락·완주 기록을 복원합니다. 결과 확정 시 연결이 끊긴 사람, 관전자, 개발용 봇은 선정하지 않습니다.

결과는 경기당 한 번 확정합니다. 같은 결과 재수신·새로고침·종료 중복 입력으로 다시 선정하지 않습니다. 재경기는 새 경기 ID로 초기화합니다. 종료 이유는 정상 종료 또는 교사 강제 종료입니다. 이전 인터페이스 호환을 위해 타입에 남은 timeout 값은 현재 자동 경기에서 생성하지 않습니다.
